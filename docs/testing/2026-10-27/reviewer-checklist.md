For visual tests, a correct description without the requested inline image is a presentation failure/partial result, even when retrieval found the right picture. A missing caption is not automatically a failure if none was identified and the limitation is explicit. Image-descriptions can transcribe incorrectly: check numeric answers against the actual picture.

Do not require a fixed ranked result list: replica indexes and model choices can vary. Judge the final supported facts and images, then inspect whether the tool path met the requested full-file scope. Record both quality and cost; a cheaper answer that misses evidence is not an improvement.
